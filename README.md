# 个人智能操作系统

这里用于沉淀个人实践中的认知、复盘认识和复盘工具，让重要判断能够被记录、修订，并在后续实践中继续检验。

## 内容

### 个人实践认知表达

记录长期实践中的对象、关键关系、判断依据、适用条件和未解决问题。重点保留从最终成果中看不出来、但会影响后续判断的认识。

### 复盘认知

整理对复盘对象、作用和边界的认识，关注复盘如何帮助发现问题、修正认知，并影响后续实践。

### 复盘工具

维护支持复盘记录、认知更新和后续回看的工具。工具服务于实际实践，不替代个人判断。

## 内容之间的关系

实践中形成的观察和反馈可以进入复盘；复盘所得的新认识可以推动相关实践认知的修订，并影响后续行动。后续实践的结果再用于检验或修正这些判断。

这是一种持续改进方向，不意味着每次复盘都必须产生规范、代码或工具改动。

## 记录原则

- 区分事实、证据、解释和待验证判断。
- 记录重要判断的理由、适用条件和认识边界。
- 不把文档存在等同于本人已经理解，也不把单次成功等同于方法已经有效。
- 根据实际内容和维护需要组织目录，不为填满结构而编造内容。

## 当前状态

仓库内容将随个人实践逐步形成和修订。各部分的成熟度与检验状态分别判断。
