# 复盘认知

## 实践对象与核心问题

复盘是主体回看真实实践、形成或修正判断，并让判断影响后续实践的认知活动。核心问题是：复盘得到的认识，怎样进入相关实践认知并影响后续行动，再由新的实践反馈继续检验？

## 一、对象、关系与作用机制

复盘围绕一段有边界的真实实践展开，需要把实践情境、预期、实际观察、证据、当前解释和后续判断联系起来。它的认知价值不只在回顾结果，也在于识别哪些判断得到支持、哪些条件被忽略、哪些解释仍不确定，以及这些认识是否会改变后续实践。

可检验的关系是：实践产生观察与反馈；主体据此形成复盘判断；判断可能促使相关实践主题更新，或引出有条件的行动调整；后续结果再支持、修正或推翻该判断。这是待检验的关系模型，不是已证明的普遍因果链。

## 二、认识边界

- 复盘记录本身不证明判断正确，也不证明实践已经改善。
- 应区分观察事实、个人解释和因果推断，避免把未经验证的归因写成确定结论。
- 复盘不等同于周记、工作流水或增加记录长度；频率和形式应服务于具体实践。
- 不要求每次复盘都更新认知资产、制定新任务或改动工具。没有变化时，也可以记录判断保持不变的依据。

## 三、实践行动认知

当复盘发现原判断与实际结果不符，或出现会影响后续实践的新证据时，可先判断问题属于对象认识、依据不足、行动条件变化还是执行偏差，再比较可选调整及其代价。选择行动时，应说明适用条件、责任主体、预期观察结果和回看时机；证据不足时，保留不确定性或先补充观察，不把暂时解释直接变成通用规则。

这描述的是有条件的行动判断，不是固定复盘流程或任务清单。具体行动由实践主体根据当时的目标、条件和责任决定。

## 当前认识状态与待检验问题

本页是初始认知框架，依据 2026-11-24 团队讨论班《任务承载（v2）》中的 B04 任务说明整理，尚未经过个人实践检验。材料指出，若复盘只留下分散记录、没有后续认知更新与行动反馈，就难以形成可持续闭环；这仍是需要在个人实践中检验的判断。

开放问题包括：哪些复盘值得更新主题资产？什么证据足以支持调整？如何判断后续变化与复盘之间是否有关？怎样避免为闭环而制造无必要的任务？
