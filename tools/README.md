# 复盘工具

## 新建复盘记录

在仓库根目录运行：

```bash
python tools/new_review.py
```

工具按本机日期在 `reviews/<年份>/<日期>-review.md` 新建记录。补记时可指定日期：

```bash
python tools/new_review.py --date 2026-11-24
```

目标文件已存在时，工具会停止且不会覆盖。记录模板要求梳理实践情境、观察依据、新判断、相关认知资产和可观察的后续行动。

## 工具边界

脚本只创建记录，不判断复盘结论是否正确，不自动修改实践主题，也不自动生成或执行任务。使用者需要依据证据自行判断是否更新认知资产，并在后续实践中回看结果。
