# 个人实践认知表达

本部分用于索引个人长期实践中形成的认知资产，重点表达真实实践对象、核心问题、关键关系、判断理由、适用条件、认识边界和开放问题。它不等同于工作流水、论文清单或成果文件集合。

## 当前主题

- [硕士学位获取实践主题（Uri）](https://github.com/suanhaitech/em-exp/tree/develop/topics/uri_master_degree)：围绕个人硕士学位获取实践，覆盖培养流程、要求和相关判断。

该主题目前由科研小组表达仓 `em-exp` 主维护。本仓保留入口而不复制全文，以免形成需要同步的第二份主版本。主题的培养信息和依据以其维护位置为准。

## 后续纳入原则

新增个人实践主题时，先辨认真实对象、核心问题、适用范围和长期认知价值，再决定由本仓承载还是引用其他主维护位置。若本仓需要形成与其他范围不同的独立认识，应写清范围、依据和维护责任；不因目录存在就视为认识已经成熟。
